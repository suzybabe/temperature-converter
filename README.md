# temperature-converter
Temperature converter with pure CSS, Javascript and HTML.
This is a simple temperature converter I created using HTML, CSS and JavaScript.

## What it does

It allows the user to:

- Convert Fahrenheit to Celsius
- Convert Celsius to Fahrenheit

## Technologies Used

- HTML
- CSS
- JavaScript

## How to use

1. Enter a temperature.
2. Select the conversion you want.
3. Click the Enter button.
4. The converted temperature will be displayed.
